## [0:52–1:30] THE REAL PROBLEM

**(Slide: A DECISION IS NOT A PROMPT. IT'S A CONTRACT.)**

> Here's the reframe. A text model returns prose. Your code then guesses whether the prose means yes — string matching, silent failures. That guessing layer is where AI features quietly die.
>
> A typed decision inverts it. Unstructured state in. A **typed answer** out — a choice, a score, a probability. Your code doesn't parse it. Your code **compares** it.

**(Slide: THE THREE INGREDIENTS OF A CONFIDENT MISTAKE)**

> And here's what nobody on your timeline is telling you. A wrong decision is a bug. A *confident* wrong decision, wired to an irreversible action, is an incident. Every one needs three things: an uncalibrated threshold, no review path, and an action-mapping error.
>
> Remove any one — it's a log line instead of an outage.

## [1:30–2:20] THE MECHANISM — the JEVLINE Loop

**(Slide: JEVLINE: ASK → SHAPE → CALIBRATE → GATE)**

> This is the system. Four words.
>
> **ASK** — one narrow question. Ask *facts*, not decisions. The model answers "was a refund requested?" Your code decides whether to grant it.
>
> **SHAPE** — pick the answer your code can consume. Noul for gates. Choice for routers. Score for ranking. If you're parsing strings, you picked wrong.
>
> **CALIBRATE** — freeze the decisions, sweep the threshold, plot your false-auto-route rate against your review load. Then quote the number from the holdout you never tuned on.
>
> **GATE** — allow, review, refuse. Never a bare yes-or-no. When in doubt, do the reversible thing.
